ЗАПУСК БОТА 24/7 НА ХОСТИНГЕ ТЕЛЕГРАМ-БОТОВ

1) Загрузи на хост ВСЕ файлы из этого архива (папка bot/, main.py, requirements.txt, .env.example, db/ ...).
   Запускающий файл:  main.py      Команда запуска:  python main.py      Python: 3.10 или новее.
   Зависимости ставятся из requirements.txt (хост обычно делает это сам).

2) Переменные окружения (раздел Variables / Env / .env на хосте) — смотри .env.example:
   BOT_TOKEN   — токен от @BotFather (обязательно)
   WEBAPP_URL  — ссылка на мини-апп (GitHub Pages), обязательно с https://
   OWNER_ID, ADMIN_IDS — кто админ.
   Firebase настраивать не надо.

3) ВАЖНО: останови бота на своём компьютере! Один токен = один работающий бот.
   Если запущены две копии — будет ошибка «Conflict: terminated by other getUpdates request».

4) Данные (db/): пользователи, рефералы, баны хранятся файлами. Если хост стирает файлы при перезапуске,
   включи постоянный диск/том и укажи путь в NX_DATA_DIR. Баны дополнительно дублируются в Firebase.
   Перед переездом скачай папку db/ со старого места и положи на новое.

5) Проверка: напиши боту /fscheck (админ) — должно быть WRITE 200 и READ 200.

КОМАНДЫ АДМИНА В БОТЕ
   /ban <id или @username> [причина]   — бан в боте и в мини-аппе
   /unban <id или @username>           — снять бан
   /bans                               — список банов (также кнопка «Баны» в Админ-панели)
   /refreset <id>                      — снять привязку реферала
   /fscheck                            — проверка Firebase
   В мини-аппе: Профиль -> Админ-панель -> блок «Баны».
